# 🚀 라이브 커머스 실시간 AI 주문 접수 & OBS 자막 서버

유튜브, 인스타그램, 틱톡 3개 라이브 방송의 채팅을 실시간으로 수신하여, **AI(GPT-4o-mini)로 주문/질문/일반대화를 자동 판별**하고, **실시간 엑셀(`live_orders.xlsx`) 저장** 및 **OBS 방송 자막(`obs_ai_reply.txt`) 생성**을 동시에 처리하는 실전 라이브 커머스 자동화 서버입니다.

---

## 📁 프로젝트 구성

| 파일명 | 설명 |
| :--- | :--- |
| `start_server.bat` | **[원클릭 실행]** 더블클릭만으로 패키지 점검 및 서버 구동 |
| `live_commerce_server.py` | 메인 Flask 웹 서버 (웹훅 수신, AI 의도 분석, 엑셀/OBS 자막 연동) |
| `catalog.py` | 오늘 방송할 상품 목록, 옵션, 가격 및 배송/교환 정책 설정 |
| `test_chat.py` | 실제 방송 전 로컬에서 주문/질문/일반 채팅을 전송해보는 시뮬레이터 |
| `.env` | OpenAI API 키 및 서버 포트 설정 파일 |
| `requirements.txt` | 필요 파이썬 패키지 목록 (`flask`, `flask-cors`, `openai`, `openpyxl` 등) |
| `live_orders.xlsx` | *(자동생성)* 접수된 주문이 실시간 누적 기록되는 엑셀 파일 |
| `live_orders_backup.csv`| *(자동생성)* 엑셀 파일 열람 잠금 시 데이터 유실 방지용 실시간 백업 파일 |
| `obs_ai_reply.txt` | *(자동생성)* OBS Studio 방송 화면에 띄울 최신 AI 답변 자막 파일 |

## ⚡ 빠른 시작 가이드 (3분 완성)

### 1단계: OpenAI API 키 설정 (선택/권장)
`.env` 파일을 열고 본인의 OpenAI API 키를 입력합니다.
```env
OPENAI_API_KEY=sk-proj-xxxx...
```
*(키를 입력하지 않은 상태에서도 내장된 모의 AI 엔진을 통해 기본 테스트가 가능합니다.)*

### 2단계: 서버 실행
`start_server.bat` 파일을 더블클릭하거나, 터미널에서 다음 명령어를 실행합니다:
```bash
python live_commerce_server.py
```
콘솔에 아래 문구가 나타나면 정상 대기 상태입니다:
> `🚀 라이브 커머스 통합 AI 서버가 시작되었습니다! (http://127.0.0.1:5000/chat)`

## 🔗 실전 연동 방법

### 1. Social Stream Ninja (크롬 확장 프로그램) 연동
1. 크롬 웹 스토어에서 **Social Stream Ninja**를 설치합니다.
2. 확장 프로그램 설정(Options) ➔ **Mechanics / Integrations** (또는 **Webhook / Server API**) 메뉴로 이동합니다.
3. **Post chat messages to a custom Webhook URL** 옵션을 켜고 아래 주소를 입력합니다:
   ```text
   http://127.0.0.1:5000/chat
   ```
4. 크롬 브라우저 탭에 유튜브/인스타그램/틱톡 라이브 방송 관리자 채팅창을 띄워두면 모든 시청자 댓글이 파이썬 서버로 자동 전송됩니다.

### 2. OBS Studio 실시간 자막 배너 연동
1. **OBS Studio** 실행 후 하단 **소스 목록**에서 **+** 버튼 ➔ **텍스트 (GDI+)** 선택.
2. 설정 창에서 **'파일에서 읽기'**에 체크.
3. `찾아보기`를 눌러 본 프로젝트 폴더의 `obs_ai_reply.txt` 파일을 선택.
4. 글꼴, 텍스트 크기, 배경색(예: 반투명 검정 배경, 흰색 글씨)을 지정하고 방송 화면 하단에 배치합니다.
5. 시청자가 질문이나 주문을 남길 때마다 1초 내로 방송 화면 배너 자막이 자동 갱신됩니다!

## 🧪 사전 검증 시뮬레이션 (`test_chat.py`)
실제 라이브 방송을 켜기 전에 모든 기능이 정상 작동하는지 원클릭으로 테스트할 수 있습니다.
새 터미널 창을 열고 아래 명령어를 실행하세요:
```bash
python test_chat.py
```
유튜브, 인스타그램, 틱톡의 가상 채팅(주문, 사이즈 문의, 배송 질문, 감탄사 등) 5건을 순차 전송하며 다음을 자동 검증합니다:
1. `live_orders.xlsx`에 주문자 닉네임, 상품명, 색상, 사이즈, 수량이 정상 기록되는지 확인
2. `obs_ai_reply.txt`에 방송용 친절 답변이 실시간 갱신되는지 확인

## 🛡️ 실전 운영 안심 기능 (엑셀 파일 잠금 방지)
- 윈도우 환경에서는 엑셀(`live_orders.xlsx`)을 열어두면 쓰기 잠금(`PermissionError`)이 발생합니다.
- 본 서버는 방송 중 호스트나 스태프가 엑셀을 열어보더라도 주문이 유실되지 않도록 **`live_orders_backup.csv` 실시간 비상 백업** 및 **메모리 대기 큐 자동 동기화 기능**이 내장되어 있습니다.
